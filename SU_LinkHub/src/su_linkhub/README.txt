SU LinkHub v0.13.6.192

本版新增（详见 CHANGELOG_v0.13.6.192.txt / CHANGELOG_v0.13.6.191.txt / CHANGELOG_v0.13.6.190.txt）：
- 六面代理：修复“方盒/地毯类代理图像不是 RGBA”、“迎宾册类待刷新家具无法建立六面代理候选”；远端隔离截图拍空后自动改走近原点，代理生成约快一半。
- 扩展程序 → SU LinkHub → LinkHub 只读诊断（选择/双击诊断、家具变形诊断、导出日志诊断包），右键菜单同样可用；全部只读。

- 发布/入库不再因个别家具缺代理而整单失败：缺代理家具以真模型随包发布，代理后台补齐。
- 来源同步不再把正在调整的联动副本弹回；发布前复核协同组件签名，避免“显示最新但内容旧”。

SU LinkHub v0.13.6.163

本版以 v0.13.6.160 为稳定基线，开始分阶段整理交互与后台任务架构。
详细改动与验证范围见 CHANGELOG_v0.13.6.163.txt。

本阶段的重点：
- 普通选择不再反复读取完整 project_json，也不再无条件扫描联动空间定义图。
- 抽屉已展开时，选中对象只刷新顶部快捷动作，保留最近一次完整卡片树。
- 点击发布后的原生候选准备缩短无操作交接时间；双击、工具操作、组件层级和重任务门禁继续生效。
- 正式共享 SKP/manifest 提交与安全快照、历史归档、个人快照拆成两个串行通道。
- 后发布整理自动给新的正式发布让路；整理失败只报告警告，不会把已成功的正式发布改成失败。
- 发布轮询只在状态阶段变化时写模型提示，不再按心跳重复读取项目或落盘队列快照。
- 发布结果使用任务 ID 收尾，旧任务不能覆盖同空间的新任务状态。
- 日志文件名恢复与实际插件版本一致，便于现场定位。

日志目录：%TEMP%\SU_LinkHub\logs\
主日志：SU_LinkHub_v0.13.6.163.log
后台发布诊断：SU_LinkHub_后台发布诊断_v0.13.6.163.log

SketchUp 模型与视图 API 仍只在主线程执行；后台线程只处理候选校验、共享文件提交、快照和归档等纯文件任务。
